# Perubahan Form Pelanggan

- Form input pelanggan di halaman utama Admin dan Sales dihilangkan.
- Tombol Tambah dan Ubah membuka dialog popup berisi Nama Pelanggan dan Nomor Telepon.
- Tombol Hapus tetap berada di halaman utama dan memerlukan pemilihan baris tabel.
- Input divalidasi melalui PelangganController sebelum disimpan.
- Tampilan tabel pelanggan tetap menampilkan ID, Nama, dan Nomor Telepon.

Build source telah diperiksa menggunakan `javac` JDK 21. Pengujian runtime dengan MySQL perlu dilakukan pada komputer yang menjalankan database.
